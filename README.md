# Performance Playground

This repo features some fun expirements/profiling to help myself learn about low latency and high performance software. 
It is also a fun way for me to procrastinate studying for my finals...


## Environment

### Machine

- Device: Macbook Air
- Chip: Apple M1
- CPU Architecture: ARM 64 / Apple Silicon
- CPU Cores
	- 4 Performance Cores
	- 4 Efficiency Cores
- Memory: 8 GB unified memory
- Cooling: Fanless passive cooling

### Operating System

- OS: MacOS 15.6.1
- Kernel: Darwin 24.6.0

### Compiler

- Compiler: Apple clang++ 16.0.0
- Target: arm64-apple-darwin24.6.0
- C++ Standard: C++20
- Build Type: Release
- Optimization Flags: `-O3 -DNDEBUG`
